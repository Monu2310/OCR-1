# OCR-1

Simple OCR (Optical Character Recognition) tool to extract text from images. (in development , PATENT project can't tell much until completed)

## Installation

```bash
git clone https://github.com/Monu2310/OCR-1.git
cd OCR-1
pip install -r requirements.txt
```

## Usage

```bash
python ocr.py input_image.jpg
```

## Requirements

- Python 3.x
- Tesseract OCR

## Supported Formats

- JPEG, PNG, TIFF, BMP

## Output

Extracted text will be saved as `output.txt`
